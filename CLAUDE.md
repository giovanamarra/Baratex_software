## Identidade visual

Antes de criar ou alterar qualquer template, HTML ou CSS, leia `docs/design/BRAND.md`. Use só as variáveis de `static/css/tokens.css` (nada de hex solto no CSS ou nos templates) e os logos de `assets/`. Limão `#9CFF00` nunca é cor de texto em fundo claro.
